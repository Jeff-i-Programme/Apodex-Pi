融合是 **Research Pi 底座 + 嵌进去的科学小板块**，不是另开评测环。交 TRACE 仍是一个 agent。`RESEARCH_PI_SCIENCE=0` 只对照师兄原版。下面分数来自 executable-world 五题、`apodex-1.1`、seed 0。

| 简称 | 是什么 |
|---|---|
| Harness | 本仓库 `apodex_harness.solve`，策略层直接驱 EW |
| 原版 Pi | 师兄 Apodex-Pi，科学扩展关闭 |
| 融合 Pi | 同一 Pi，打开 scientific-loop、科学工具、交卷对齐 |

## 原版 Pi 保留了什么

研究合同没有拆掉。只有当前观察是隐藏世界、类型化动作、仪器读数、或必须写出指定结果文件时，才启用科学条款。

| 能力 | 落点 |
|---|---|
| 假设、证据、Project memory、Codex | `APPEND_SYSTEM.md` 其余各节；`record_experiment` 只记改变判断的结果 |
| Leader / Analysis 与 mailbox | Research Runtime；print 评测可接管 Leader |
| 证据与工作分离 | 跑通命令或写出文件只证明做了工，不是科学证据 |
| 按 brief 逐步探测、嵌套交卷 | 采购题 `ep.act("submit", {"plan": ...})`，这是原版 0.96 的来源 |
| 对照开关 | `RESEARCH_PI_SCIENCE=0` 关掉科学扩展 |

TPM 间隔、滚动 token 窗、429/断线重试是为了让两边都能跑完，不是科学策略。

## Harness 嵌进去的能力

只加换题、换 seed 仍成立的条款，落在同一个 scientific-loop，不是第二个 agent。

| 能力 | 落点 |
|---|---|
| 便宜探针、分叉、错了改调用 | scientific-loop：Spend, split, recover |
| 镜像副本、永不重复的生成器、陈述的垃圾上限硬门、未核字段须核查或声明 | 合同科学节 + skill |
| 交卷跟 brief 走 | `submit(plan/finding/strategy)` 必须包一层；摊平或改名当成空提交 |
| 预算内先交再改 | 催交；有多次提交则零分后改 |
| 具身实验介质 | 钥匙则开、开门后穿过、仪器对样品、给人用 PUT |
| 读数选题 | `science_note_measurement`：oldest / outlier / contaminated |
| 科学程序写出指定文件 | `science_run_program`；缺包改写现成栈 |
| Windows 主机环境 | 直接调 Python，不依赖 Git Bash 才能跑科学程序 |

Harness 循环另外保留：未花掉的预算不挡催交；提交前若轨迹显示再抽样无交集或判定过半垃圾，从 crawl 拿掉并标 decoy。

## 三方测题对照

测的是方法切面，不是场景脚本。分数取自 `results/three-way/20260904-capability/summary.json`。

| 题 | 测的能力 | Harness | 原版 Pi | 融合 Pi |
|---|---|---:|---:|---:|
| verify_solutions | 便宜分叉探针，预算内提交 | 1.0000 | 1.0000 | 1.0000 |
| clinical_signal | 未核字段须核查或声明（硬门） | 1.0000 | 1.0000 | 1.0000 |
| corpus_dedup | 经验去重 / 防泄漏，可按反馈改交 | 1.0000 | 0.7055 | 1.0000 |
| treatment_response | 不用泄漏或禁列 | 1.0067 | 1.0067 | 1.0067 |
| corpus_procurement | 经验 decoy + 陈述的垃圾上限硬门 | 0.8000 | 0.9600 | 0.9000 |
| 五题均分 | — | 0.9613 | 0.9344 | 0.9813 |

treatment_response 允许超过 1.0：1.0 表示打平「全部合法列」基线，再去掉无信号列会略高。

**去重题** 原版 0.7055，Harness 与融合都是 1.0000——Harness 的「经验重复 / 按反馈改交」进融合后保住了。

**采购题** 先前融合和 Harness 都是 0，因为交卷摊平读到空 `plan`。对齐包装后三方都过硬门、都拿到全部 oracle 高价值 token。剩下分差是 decoy F1 和区间，不是空计划。

| | 硬门 | oracle token | decoy F1 | 区间盖住 133 | 分 |
|---|---|---|---:|---|---:|
| 原版 Pi | 过 | 全部 | 0.80 | 是 | 0.96 |
| 融合 Pi | 过 | 全部 | 0.50 | 是 | 0.90 |
| Harness | 过 | 全部 | 0.50 | 否（lo=140） | 0.80 |

融合五题均分最高（0.9813）：去重跟住 Harness 的 1.0，采购跟住原版同一量级。原版被去重 0.7055 拉低，Harness 被采购 0.80 拉低。

> 原版留下研究合同和「按 brief 逐步探测再嵌套交卷」；Harness 留下经验硬门、交卷 schema、具身实验介质和科学程序必须写出指定文件。融合是同一个 agent 同时用两边，不是两个环。
